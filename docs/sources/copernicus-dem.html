What it is

The Copernicus DEM is a digital surface model: as its AWS readme puts it, it represents the surface of the Earth “including buildings, infrastructure and vegetation”. It comes in two public instances, GLO-30 at 30 m, not yet released everywhere, and GLO-90 at 90 m, with worldwide coverage. The copy on Amazon’s open-data registry is cut into 1° tiles as cloud-optimised GeoTIFFs and is free for the general public under the Copernicus DEM licence.

Kosovo spans six GLO-90 tiles. Because the files are cloud-optimised, GDAL reads only the blocks it needs, and the crop is cached here. The six tiles are combined into one virtual mosaic (terra::vrt()) before cropping, so the code does not need to know which tile holds which part of the country; the tile names follow a fixed pattern of latitude and longitude, which the helper tile_url() above writes out.

Show the remote crop 
build_error <- NULL
if (!file.exists(cache)) {
  build_error <- tryCatch({
    Sys.setenv(GDAL_DISABLE_READDIR_ON_OPEN = "EMPTY_DIR")
    tiles <- expand.grid(lat = 41:43, lon = 20:21)
    r  <- vrt(paste0("/vsicurl/", mapply(tile_url, tiles$lat, tiles$lon)))
    ko <- vect(kosovo_outline())
    k  <- round(mask(crop(r, ko, snap = "out"), ko))
    writeRaster(k, cache, overwrite = TRUE, datatype = "INT2S",
                gdal = "COMPRESS=DEFLATE")
    NULL
  }, error = function(e) conditionMessage(e))
}
have_cache <- file.exists(cache)

What it adds for Natura 2000 in Kosovo

Elevation separates habitats the land-cover data cannot: alpine grassland from lowland grassland, subalpine beech from thermophilous oak. The altitude belts above give the representation test of question 4 (“every altitude belt covered”) its denominator, and a terrain model is one of the layers the boundary workflow of question 2 draws along (watersheds, ridges). GLO-90 serves the national tier; GLO-30, if available, would come closer to site work.

Caveats and sensitivity

  • A surface model: in forest it measures the canopy, not the ground.
  • At 90 m, narrow gorges and ridges are smoothed.
  • No sensitive content.

Integration into the pipeline

Low effort. A proposed kosovo_dem(boundary) in R/functions.R would do the crop above and cache data/kosovo_dem_glo90.tif; the habitat screen could then split its classes by altitude belt, much as it splits them by biogeographical region today. pipeline.R is not changed.

## Kosovo coverage check

```{r}

#| eval: !expr have_cache
k <- rast(cache)
inside <- !is.na(values(rasterize(vect(kosovo_outline()), k), mat = FALSE))
v <- values(k, mat = FALSE)[inside]
area <- values(cellSize(k, unit = "km"), mat = FALSE)[inside]
belts <- cut(v, c(-Inf, 500, 1000, 1500, 2000, Inf),
             labels = c("below 500 m", "500–1,000 m", "1,000–1,500 m",
                        "1,500–2,000 m", "above 2,000 m"))
tab <- tapply(area, belts, sum)
knitr::kable(data.frame(`Altitude belt` = names(tab),
                        `Area (km²)` = fmt_int(tab),
                        Share = sprintf("%.1f %%", 100 * tab / sum(tab)),
                        check.names = FALSE), align = "lrr", row.names = FALSE)
```

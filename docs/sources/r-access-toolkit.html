What it is

Every page in this section reaches its data from R, with a handful of packages. This page lists them with the version CRAN offered on the day of the check and the version installed where the site was rendered, what each reaches, and, because it decides whether a Kosovo query returns anything, how each identifies Kosovo. rgbif and CoordinateCleaner are already used by pipeline.R and are listed for completeness.

Kosovo coverage check

The question for a toolkit is how each package names Kosovo, and three of the answers were tested in this session rather than taken from documentation.

Show the code 
cc <- geodata::country_codes()
cc[cc$NAME == "Kosovo", c("NAME", "ISO3", "ISO2")]
      NAME ISO3 ISO2
120 Kosovo  XKO   XK
Show the code 
g <- tryCatch(giscoR::gisco_get_countries(resolution = "20", year = "2024"),
              error = function(e) NULL)
if (!is.null(g)) {
  print(sf::st_drop_geometry(g[g$CNTR_ID %in% c("XK", "RS"), c("CNTR_ID", "ISO3_CODE", "NAME_ENGL")]))
  print(sf::st_bbox(g[g$CNTR_ID == "RS", ]))
}
    CNTR_ID ISO3_CODE NAME_ENGL
142      RS       SRB    Serbia
    xmin     ymin     xmax     ymax 
18.87271 41.86428 23.00621 46.18793

GISCO’s 2024 country layer has no feature for Kosovo, and Serbia’s polygon reaches south to about 41.86° N: Kosovo is inside it. The pipeline already knows this (R/functions.R compares its border against GISCO’s international boundary only), but anyone who clips data to “Serbia” from GISCO is clipping Kosovo in with it.

Across this section, Kosovo turned up under at least six different identifiers: XK (GBIF, EU country code), XKO (GADM, geodata), XKX (the pipeline’s own ISO3-style code), KS (EFFIS), RS (Emerald candidate sites, BirdLife’s inventory and GISCO, where it is merged into Serbia), and Ko (Euro+Med). A script that filters any of these sources by one code will silently miss what the others file under another.

What it adds for Natura 2000 in Kosovo

Reproducibility. Every figure on these pages can be recomputed with free software from the sources’ own servers, and each check is shown as code a participant can run and change. Tier: not applicable.

Caveats and sensitivity

  • rredlist, eurostat and ows4R are on CRAN but were not installed where the site was rendered, so their Kosovo behaviour is not tested here.
  • Versions move; the table records the day of the check.

Integration into the pipeline

pipeline.R already loads rgbif, sf, CoordinateCleaner and friends. The pages here would add terra (rasters) and eunis.habitats (crosswalk) if their proposed functions are adopted. pipeline.R is not changed.

What it is

eBird, run by the Cornell Lab of Ornithology, and Observation.org are the two citizen-science platforms that contribute most to Kosovo’s GBIF record. Both publish to GBIF: eBird as the “EOD – eBird Observation Dataset” under CC BY 4.0, Observation.org as “Observation.org, Nature data from around the World” under CC BY-NC 4.0. Both are already among the datasets in the report’s download, and eBird alone supplies nine in ten of its bird records.

The desk review asked about records not in GBIF. For eBird that means the eBird Basic Dataset (EBD). The site’s Natura 2000 page describes it as carrying what the GBIF copy leaves out: the effort fields and the flag that says a checklist reports every species detected, which turn a list of sightings into a survey with non-detections. eBird’s own description could not be read to confirm this (see Access). For Observation.org it means records the platform does not pass to GBIF.

Show the GBIF check 
if (!file.exists(cache)) {
  res <- tryCatch({
    reg <- read.csv(file.path(sources_root(), "data", "dataset_registry.csv"))
    do.call(rbind, lapply(names(keys), function(n) {
      q <- function(extra) jsonlite::fromJSON(sprintf(
        "https://api.gbif.org/v1/occurrence/search?datasetKey=%s&limit=0%s", keys[[n]], extra))
      g <- q("&gadmGid=XKO&facet=country&facet=year&facetLimit=100")
      cc <- g$facets$counts[[which(g$facets$field == "COUNTRY")]]
      yr <- as.integer(g$facets$counts[[which(g$facets$field == "YEAR")]]$name)
      data.frame(platform = n, records_in_gadm_xko = g$count,
                 records_coded_xk = q("&country=XK")$count,
                 codes_inside_gadm = paste(sprintf("%s %s", cc$name, cc$count), collapse = "; "),
                 years = sprintf("%d–%d", min(yr), max(yr)),
                 in_report_download = keys[[n]] %in% reg$datasetKey)
    }))
  }, error = function(e) NULL)
  if (!is.null(res)) write.csv(res, cache, row.names = FALSE)
}

What it adds for Natura 2000 in Kosovo

An SPA case needs counts with effort, not scattered presences (question 6). The EBD’s effort fields and complete-checklist flag are what make eBird usable for that: they allow detection rates, seasonal occupancy and absences to be computed for Ligatina e Hencit/Radevës and the other bird sites. Stationary counts with precise locations can reach the delineation tier; travelling checklists stay at screening.

Caveats and sensitivity

  • The EBD terms could not be read; the licence of the full eBird database is therefore not recorded.
  • Both platforms hide or generalise sensitive species in their public data; what applies to Kosovo is unknown.
  • Observation.org’s GBIF copy is CC BY-NC, which limits commercial reuse of anything derived from it.

Integration into the pipeline

Medium effort for the EBD: a proposed read_ebd(path, boundary) using the auk package would filter the file to Kosovo and keep checklist-level effort beside the GBIF records, linked by checklist identifier rather than merged. pipeline.R is not changed.

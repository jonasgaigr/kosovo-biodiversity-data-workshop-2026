What it is

Under the Bern Convention each Party proposes Emerald sites, and regional biogeographical seminars then judge, species by species and habitat by habitat, whether a country’s list is sufficient. The share of features found sufficient is reported as a sufficiency index. For Kosovo’s neighbours the index says how complete their networks are along the shared mountains, and therefore how much of a transboundary network already exists on the other side of the border.

The figures below come from a secondary source only. CEE Bankwatch Network reported on 9 December 2024, after the 44th meeting of the Convention’s Standing Committee, that all Western Balkan countries must reach a 35 per cent sufficiency target by 2030, and gave each country’s current index. The primary Council of Europe documents could not be opened.

Country Sufficiency index (Bankwatch, 9 December 2024)
Serbia 13.5 %
North Macedonia 16 %
Montenegro 16.3 %
Albania 28.3 %

Kosovo coverage check

The sufficiency index is a national figure and says nothing about Kosovo directly. What can be checked is what each neighbour has put on the ground near Kosovo.

Show how the neighbours’ sites near Kosovo are counted 
build_error <- NULL
if (!file.exists(cache)) {
  build_error <- tryCatch({
    source("../R/functions.R", local = TRUE)
    ko   <- st_transform(st_union(kosovo_outline()), 3035)
    zone <- st_buffer(ko, 50000)
    s <- arcgis_query_sf(service, st_bbox(st_transform(zone, 4326)),
                         fields = "SITECODE,SITENAME,COUNTRY_CODE,SITESTATUS",
                         verbose = FALSE) |> st_make_valid()
    s <- s[lengths(st_intersects(s, zone)) > 0, ]
    ring <- st_difference(zone, ko)
    s$ha_in_ring <- vapply(seq_len(nrow(s)), function(i)
      sum(as.numeric(st_area(st_intersection(st_geometry(s)[i], ring)))), 0) / 1e4
    write.csv(st_drop_geometry(s), cache, row.names = FALSE)
    NULL
  }, error = function(e) conditionMessage(e))
}
have_cache <- file.exists(cache)

Status of the 33 sites within 50 km of Kosovo: Candidate 33. None has been adopted. Read with the sufficiency figures, the transboundary network Kosovo would join is itself unfinished on every side.

What it adds for Natura 2000 in Kosovo

It sets expectations. If the neighbours have proved between 13 and 28 per cent of their features sufficient, as the secondary source reports, a Kosovo network will be judged in a region where few boundaries are settled. It also flags a practical risk: the Serbian candidate sites inside Kosovo (see Emerald Network) may enter Serbia’s statistics, and a Kosovo sufficiency ledger (question 4) should not count the same ground twice.

Caveats and sensitivity

  • The four percentages are secondary. Until the Council of Europe document is read, treat them as reported, not verified.
  • Sufficiency is judged per biogeographical region; a single national figure hides regional differences.
  • The index is a share of features, not of territory.

Integration into the pipeline

No pipeline step is needed for the index itself: it belongs in the report as a small table with its source and date. The site layer is covered by the proposed emerald_sites_near() on the Emerald Network page. pipeline.R is not changed.

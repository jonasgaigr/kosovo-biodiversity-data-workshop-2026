What it is

Fauna Europaea is a checklist of Europe’s animals that records which species occur in which European country. The desk review asked whether it treats Kosovo as an area of its own or folds it into Serbia. That question could not be answered in this check. The project’s web domain did not resolve, and the copy of the checklist published to GBIF (DOI 10.15468/ymk1bx, dated 9 September 2016, licence “unspecified”) holds names without the distribution data that would show Kosovo.

Kosovo coverage check

The executable check asks the GBIF copy for the distribution records of a few well-known species that occur in Kosovo.

Show the code 
probe <- c("Rupicapra rupicapra", "Ursus arctos", "Salamandra salamandra",
           "Lycaena dispar", "Rosalia alpina")
res <- do.call(rbind, lapply(probe, function(nm) tryCatch({
  s <- jsonlite::fromJSON(paste0("https://api.gbif.org/v1/species/search?datasetKey=",
                                 key, "&limit=1&q=", utils::URLencode(nm)))$results
  d <- jsonlite::fromJSON(sprintf("https://api.gbif.org/v1/species/%s/distributions?limit=200",
                                  s$key[1]))$results
  areas <- if (NROW(d) && "locality" %in% names(d)) sum(!is.na(d$locality)) else 0
  data.frame(Species = nm, `Name found` = "yes", `Distribution areas` = areas,
             check.names = FALSE)
}, error = function(e) data.frame(Species = nm, `Name found` = "no",
                                  `Distribution areas` = NA, check.names = FALSE))))
knitr::kable(res, align = "llr")
Species Name found Distribution areas
Rupicapra rupicapra yes 0
Ursus arctos yes 0
Salamandra salamandra yes 0
Lycaena dispar yes 0
Rosalia alpina yes 0

None of the probed species carries a distribution area in the GBIF copy, so the Kosovo question cannot be answered from it.

The probe is small on purpose: five species, all of them known from Kosovo, chosen across groups. If any carried distribution areas, the next step would be to list them and look for Kosovo; since none does, a larger sample would only confirm the same absence. The check is kept on the page so that it re-runs, and flags the change, if the GBIF copy is ever republished with distributions.

What it adds for Natura 2000 in Kosovo

The animal counterpart of Euro+Med: a reference for whether an annex species is known from Kosovo at all, and so a check on GBIF records that may be new national records or errors. Only useful if Kosovo is an area of its own. It would serve the national tier.

Caveats and sensitivity

  • The checklist’s own service was unreachable; everything here rests on the GBIF copy.
  • The GBIF copy’s licence is “unspecified”.
  • No sensitive content.

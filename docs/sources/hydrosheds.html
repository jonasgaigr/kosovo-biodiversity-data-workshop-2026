What it is

HydroSHEDS is a suite of global hydrographic data derived from elevation data: flow directions, catchments (HydroBASINS) and rivers (HydroRIVERS). HydroRIVERS represents all rivers of the world as a vector network extracted from the HydroSHEDS grids at 15 arc-seconds, about 500 m, with attributes such as flow order and discharge. It is “freely available for scientific, educational and commercial use” under the HydroSHEDS licence, with attribution. Where EU-Hydro is a photo-interpreted European network at 1:50,000, HydroRIVERS is coarser and modelled, but identical in method everywhere, including across all of Kosovo’s borders.

Show the download and cut 
build_error <- NULL
if (!file.exists(cache)) {
  build_error <- tryCatch({
    if (!file.exists(zip)) {
      got <- try_access(url, zip, timeout = 900)
      if (!got$success) stop(got$error %||% paste("HTTP", got$http_code))
    }
    shp <- grep("\\.shp$", unzip(zip, list = TRUE)$Name, value = TRUE)
    ko  <- st_union(kosovo_outline())
    box <- st_as_text(st_as_sfc(st_bbox(ko)))
    r   <- st_read(paste0("/vsizip/", zip, "/", shp), wkt_filter = box, quiet = TRUE)
    r   <- suppressWarnings(st_intersection(st_make_valid(r), ko))
    st_write(r, cache, delete_dsn = TRUE, quiet = TRUE)
    NULL
  }, error = function(e) conditionMessage(e))
}
have_cache <- file.exists(cache)

What it adds for Natura 2000 in Kosovo

A river network that does not stop at the border, which matters for transboundary rivers such as the White Drin and the Ibër, and a route to HydroBASINS catchments: the watershed lines the boundary workflow of question 2 says a site boundary may follow. Coarser than EU-Hydro, it suits national screening (tier).

Caveats and sensitivity

  • Modelled from a 500 m grid: river positions can be hundreds of metres off in flat terrain.
  • No sensitive content.

Integration into the pipeline

Low effort; one download and a cut, as above. A proposed kosovo_catchments(boundary, level = 8) would be the more useful addition, for boundary work. pipeline.R is not changed.

    NULL
  }, error = function(e) conditionMessage(e))
}

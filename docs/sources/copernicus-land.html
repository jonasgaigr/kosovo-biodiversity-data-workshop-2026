What it is

The Copernicus Land Monitoring Service (CLMS), operated for this part by the European Environment Agency, produces the pan-European land products this page groups together. CORINE Land Cover (CLC) maps land cover every six years at a 25 ha minimum mapping unit, as R/functions.R records. The High Resolution Layers map single themes, such as tree cover and grassland, at a finer resolution. The Riparian Zones product maps land cover along rivers for 2012 and 2018, with a change layer between them.

One of these is already in the report. pipeline.R reads CLC2018 for Kosovo from the EEA’s map service, clips it to the OpenStreetMap outline and uses it for the screen of potential Annex I habitats; its provenance is recorded in clc_sources in R/functions.R. The desk review listed CLC as a lead, so this page records that it is in fact in use.

What it adds for Natura 2000 in Kosovo

CLC is the basis of the report’s national screen for potential Annex I habitats. The High Resolution Layers could sharpen it: a fine-grained grassland layer would separate meadows from arable land far better than a 25 ha polygon, which matters for grassland types such as 6210, 6510 and 6520. Riparian Zones would do the same for alluvial forests and river habitats, 91E0 and 92A0. All serve the national screening tier; the HRLs come closest to the site tier.

Caveats and sensitivity

  • CLC’s 25 ha unit hides small habitats entirely; the report says so where it uses it.
  • Coverage of the HRLs and Riparian Zones for Kosovo is unconfirmed.
  • No sensitive content.

Integration into the pipeline

CLC is integrated (kosovo_clc() in R/functions.R). For an HRL, a proposed kosovo_hrl(boundary, layer = "grassland") would crop the raster the same way and feed a finer grassland mask into assess_potential_habitats(). pipeline.R is not changed here.

## Kosovo coverage check

For CLC the check has already run: the pipeline's clipped extract is cached
in `data/kosovo_clc2018.gpkg`, and this page reads it.

```{r}
#| label: check
#| eval: !expr file.exists(clc_cache)
clc <- st_read(clc_cache, quiet = TRUE)
legend <- read.csv(file.path(sources_root(), "data", "clc_legend.csv"),
                   colClasses = "character")
a <- tapply(clc$area_ha, clc$clc_code, sum)
lab_col <- intersect(c("label", "clc_label", "LABEL3"), names(legend))[1]
code_col <- intersect(c("code", "clc_code", "CODE_18"), names(legend))[1]
tab <- data.frame(Code = names(a),
                  Class = legend[[lab_col]][match(names(a), legend[[code_col]])],
                  `Area (km²)` = round(as.numeric(a) / 100, 1), check.names = FALSE)
tab <- tab[order(-tab$`Area (km²)`), ]
knitr::kable(head(tab, 12), row.names = FALSE, align = "llr",
             caption = sprintf("CLC2018 in Kosovo: %s polygons, %s classes, %s km² (route: %s, read %s)",
                               fmt_int(nrow(clc)), nrow(tab),
                               fmt_int(sum(clc$area_ha) / 100),
                               unique(clc$source)[1], unique(clc$accessed)[1]))
```
